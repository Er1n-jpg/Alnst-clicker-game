A clicker game based off the popular korean animated series called "Alien Stage", Where you can click that ivan. Game was developed in godot and art was drawn through VScode

This game is a clicker game so it's pretty self explanitory what it does, when you first enter the game, you're prompted with a title screen in which you just press the big fat start button in the middle. After that you're welcomed with the main screen. The main mechanism in this game is to click the guy in the middle (Ivan) to get the in-game currency which are ivans. You can spend your ivans in the shop

The shop is accessable at the top right icon on the screen (the one with the cat and shopping cart) and will lead you to the shop screen

On the top left on the screen there is a restart button, this is if you want to clear the amount of ivans you have, this will however not clear your accessories. This game has a built in save feature, saving the amount of ivans you have for the next time you play however i'm not sure it works on the web version. The save feature will not save the accessories you have

Some accessory spots will only be avalible for one accessory at a time, such as you cannot have more than 2 plushies at a time.
